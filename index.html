Comandos Linux

O Linux é um sistema operacional muito usado em servidores, na nuvem e por desenvolvedores. Sua maior força está na linha de comando: o **Shell**.

Comandos essenciais — Navegação

  • ls — lista arquivos e pastas do diretório atual
  • cd nomeDaPasta — acessa outra pasta
  • pwd — mostra o caminho completo onde você está

Comandos essenciais — Manipulação de arquivos

  • mkdir — cria novas pastas
  • rm — apaga arquivos (use com cuidado!)
  • mv — move ou renomeia arquivos
  • cp — copia arquivos

Permissões e segurança

  • sudo — permite executar comandos como administrador
  • chmod — altera permissões de leitura/escrita/execução

Dica: Desenvolvedores web usam Linux porque é o sistema dos servidores e da Internet!

Comandos Git

O Git registra todas as versões do código, permitindo trabalho em equipe, histórico, backup e publicação em plataformas como GitHub.

Fluxo básico no Git

  1. git init — cria um repositório
  2. git add . — adiciona tudo para commit
  3. git commit -m "Mensagem" — salva versão do projeto
  4. git push — envia ao GitHub

Trabalhando com atualizações

  • git pull — baixa atualizações do GitHub
  • git clone link — copia um repositório existente

Sem o Git, seria impossível controlar tudo que muda em um site!

Plataformas de Hospedagem Estática

Sites estáticos como este (HTML + CSS + JS) podem ser publicados gratuitamente com domínio seguro (HTTPS).

Comparação das plataformas

  • GitHub Pages — ótimo para portfólios; roda direto do repositório
  • Netlify — deploy automático e formulários sem backend
  • Vercel — desempenho profissional com CDN global
  • Render — suporta sites estáticos e também APIs, com SSL grátis

Conclusão: Todas atendem bem ao ensino e início na Web — o importante é **publicar**!

HTTPS & DNS

O que é HTTPS?

O HTTPS é um protocolo de comunicação segura entre o seu navegador e o servidor do site. Ele é uma versão protegida do HTTP, usando criptografia para impedir que dados sejam roubados.

HTTP vs HTTPS

  • HTTP — sem criptografia: informações podem ser interceptadas ❌
  • HTTPS — criptografia com SSL/TLS: protege dados sensíveis ✅

O que HTTPS protege?

  • Senhas digitadas
  • Mensagens e dados pessoais
  • Dados cadastrados em formulários (login, pagamento etc.)

Sinal visual: o cadeado ao lado do endereço do site 🔒 indica conexão segura.


O que é DNS?

O DNS (Domain Name System) funciona como a “agenda telefônica” da internet. Ele converte nomes de sites (ex.: google.com) em endereços IP que os computadores entendem.

Exemplo

Você digita youtube.com 🡆 o DNS encontra o número do servidor, como: 142.250.78.174. Esse número é o verdadeiro endereço do site!

O caminho da conexão

  1. Usuário digita o nome do site
  2. O DNS encontra o IP correspondente
  3. O navegador se conecta ao servidor correto
  4. Se for HTTPS, a conexão é criptografada 🔐

✅ Resumo Final:
DNS encontra o site → HTTPS protege a conexão → Navegador exibe a página ✔

Glossário de Termos Importantes da Web

Este glossário reúne conceitos essenciais para entender como os sites funcionam na internet, desde segurança até infraestrutura e publicação de conteúdo.

  • 💻 Sistema Operacional: Plataforma onde o computador roda os programas (Linux, Windows…).
  • 🐧 Linux: Sistema operacional livre e muito usado em servidores da internet.
  • 👨‍💻 Shell: Interface de linha de comando onde comandos são digitados no Linux.
  • 📂 Repositório: Pasta monitorada pelo Git, onde o histórico do código é salvo.
  • 📌 Commit: Registro de uma “versão salva” do projeto no Git.
  • 🔄 Push: Envia alterações para o GitHub ou outra plataforma remota.
  • ⬇️ Pull: Baixa atualizações que já estão no repositório remoto.
  • ☁️ Deploy: Publicar um site na internet para que todos possam acessar.
  • 🖥️ Servidor: Computador responsável por armazenar e entregar sites aos usuários.
  • 🌐 Domínio: Nome amigável do site (ex: meusite.com).
  • #️⃣ IP: Endereço numérico que identifica dispositivos na rede.
  • 🗂️ DNS: Sistema que traduz nomes de domínio para IP — a “agenda telefônica da internet”.
  • 🔒 HTTPS: Protocolo de navegação segura com criptografia.
  • 🛡️ SSL/TLS: Tecnologia que garante a proteção de dados no HTTPS.
  • 🚀 CDN: Rede global que entrega sites mais rápido no mundo todo.
  • ⚙️ Protocolo: Conjunto de regras de comunicação entre computadores.
  • 🌍 Hospedagem Estática: Serviço que publica sites feitos com HTML, CSS e JS.
  • 🔧 Open Source: Software de código aberto que qualquer um pode estudar e modificar.
  • 🧠 Back-end: Parte do sistema que roda no servidor.
  • 🎨 Front-end: Parte visual do site que o usuário interage.
✅ Dica: Quanto mais você pratica Git, hospedagem e comandos Linux, mais fácil fica entender como a Internet funciona!
