# Resumao
Este projeto é um site estático desenvolvido com HTML, CSS e JavaScript, abordando o tema Tecnologias da Web e Publicação de Sites. O objetivo é explicar conceitos fundamentais como DNS, HTTPS, Linux, Git e hospedagem de páginas estáticas. O site inclui um simulador de orçamento, dicas práticas e infográficos simples. Também apresenta um glossário com os principais termos utilizados na internet e no processo de criação e publicação de sites. Todo o conteúdo foi organizado com foco em clareza, aprendizado interdisciplinar e aplicação prática. O projeto está publicado no Netlify e com código disponível no GitHub.
